Vice Cover Studio is an offline, GTA 6-style cover maker: load your own photos (or the bundled samples), arrange them in multi-panel layouts, pan and zoom each panel, edit the bold Anton caption and tagline, pick a Vice sunset, neon, noir or clean colour grade, and export a share-ready PNG at 1920×1080, 1080×1350 or 1080×1080 — all in the browser, with your photos never leaving your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
